# SMSClient 代码评审与深度架构诊断报告

> **项目名称**：SMSClient (Windows 4G/LTE 蜂窝短信桌面客户端 v0.2.0)  
> **技术栈**：Tauri 2 (Rust) + React 19 + Tailwind CSS 4 + bundled SQLite (WAL) + Windows WinRT API (`windows` 0.61.3)  
> **评审时间**：2026-11-08 22:30 (PST) / 2026-11-09 14:30 (CST)  
> **评审人**：Gemini 资深系统架构师

## 1. 故障 A：启动直接白屏卡死（“未响应”）根本原因诊断

白屏卡死并非单一位置的阻塞，而是 **主线程 COM STA 死锁**、**同步 Tauri Command 占用窗口线程** 与 **全局 `DbState` 互斥锁长耗时阻塞** 三者叠加导致的必然结果：

1. **原因 1：COM STA 消息泵死锁（最致命）**
   - Tauri 主线程（UI 线程）在 Windows 上初始化为 **STA（单线程套间，Single-Threaded Apartment）**。
   - 在 `src-tauri/src/lib.rs:93-102` 的 `.setup()` 钩子中，主线程直接同步调用了 `sms::sync_inbox(&guard)` 和 `sms::winrt::subscribe_inbox_events(handle)`。
   - 这两个函数内部调用了 `SmsDevice::GetDefaultAsync()?.get()`、`DeviceInformation::FindAllAsyncAqsFilter(&selector)?.get()` 以及 `SmsDevice::FromIdAsync(&id)?.get()`（`src-tauri/src/sms/winrt.rs:89-145`）。
   - 在 Windows COM/WinRT 规范中，STA 线程上的异步操作（`IAsyncOperation`）往往需要将完成回调封送（Marshal）回发起调用的 STA 线程消息队列执行；同时，无蜂窝硬件或网卡休眠的电脑在首次调用 WWAN (`WwanSvc`) 枚举时会触发服务冷启动或 PnP 超时（长达 10~30 秒甚至无限挂起）。在 STA 主线程上调用 `.get()` 会直接挂起线程、停止 Windows 消息泵（Message Pump），导致回调永远无法投递，触发经典的 **COM STA 死锁**，Windows 窗口管理器在 5 秒后将其标记为 `(未响应)`。
2. **原因 2：所有 `#[tauri::command]` 均为同步函数（`fn` 而非 `async fn`）**
   - 在 Tauri 2 中，**同步的 `#[tauri::command] fn xxx(...)` 默认直接在主 UI 线程（WebView 宿主线程）上执行**，只有声明为 `async fn` 的 command 才会被派发到 Tokio 异步线程池。
   - 当前 `lib.rs` 和 `messages.rs` 中的 `get_channel_status`、`get_sim_info`、`get_signal_strength`、`get_inbox`、`send_sms` 全部是同步 `fn`！
   - 即使把 `.setup()` 里的同步代码删掉，前端 `Dashboard.tsx:45-50` 在挂载瞬间并发调用 `Promise.all([getChannelStatus(), getSimInfo(), getSignalStrength(), getInbox()])`，这 4 个同步 command 依然会瞬间把主 UI 线程死死卡住。
3. **原因 3：持有 `DbState` 全局 `Mutex<Connection>` 锁期间执行慢速硬件 I/O**
   - 在 `lib.rs:33-79`、`lib.rs:110-117` 和 `messages.rs:158-169` 中，代码全部在 `db.0.lock()` 或 `db.with(|conn| ...)` **持有数据库互斥锁的临界区内**直接调用 WinRT 硬件探测、短信拉取和逐条删除 SIM 卡短信。
   - 一旦后台线程（15 秒心跳）正在等待 WinRT 慢速 I/O，前端发起的任何轻量级操作（甚至读取设置 `get_setting`、查联系人 `list_contacts`）都会在争夺 `DbState` 锁时彻底卡死。
4. **原因 4：`SmsChannel` 伪异步设计与冗余的 `block_on`**
   - `SmsChannel` trait 虽然声明了 `async fn`，但 `WinRtChannel` 内部全都是同步阻塞的 `.get()`，配合 `sms/mod.rs:116` 手写的 `thread::park()` 执行器 `block_on`，既没有利用异步非阻塞能力，也无法提供超时熔断保护。

## 2. 故障 B：短信收发时断时续、验证码经常漏收的根本原因诊断

结合 `src-tauri/src/sms/winrt.rs`、`src-tauri/src/sms/mod.rs` 和 `src-tauri/src/messages.rs` 的实现，验证码漏收和延迟入库主要由以下 6 个代码级漏洞引起：

| 漏洞编号 | 源码位置 | 缺陷机制分析 | 导致的线上现象 |
| :--- | :--- | :--- | :--- |
| **B1. 去重逻辑永久误杀相同验证码/指令** | `sms/mod.rs:219-226` `inbox_exists()` | SQL 为 `SELECT COUNT(*) FROM messages WHERE direction = 'in' AND phone = ?1 AND content = ?2`，**没有任何时间窗口限制**（尽管注释写了“短时间窗口内”，但 SQL 根本没写时间条件）。只要历史收到过一次相同内容（如固定测试指令、运营商流量提醒、或短时间内重发的相同验证码），后续永远被判定为 `exists = true` 直接丢弃并从 SIM 卡删除！ | 相同内容的短信或重发验证码第二次永远收不到，且被静默从 SIM 卡删掉 |
| **B2. 实时事件与轮询的双路径竞态与元数据丢失** | `winrt.rs:317-360` vs `winrt.rs:197-242` | 收到短信时，`SmsMessageReceived` 事件将完整消息（含 `PartNumber`、`PartCount`、`group_id`）推入 `PENDING_SMS`，**但不入库也不删 SIM 卡**，且只有前端主动调用 `messages::get_inbox` 时才会 `drain_pending_sms()`（`messages.rs:161`）。如果此时后台 15 秒线程先执行了 `sms::sync_inbox`（或用户在 Dashboard 页面未打开 Inbox），`sync_inbox` 会从 `MessageStore` 读出该短信并入库，但 **`WinRtChannel::get_inbox` 硬编码了 `part_index=1, part_total=1, group_id=None`（`sms/mod.rs:253-256`），丢弃了长短信分片信息**！等后来 `drain_pending_sms()` 执行时，又因为 `insert` 不做去重，导致**同一条短信在数据库里重复插入两次**！ | 长短信分片顺序错乱、消息重复入库、不在收件箱页面时实时短信无法入库 |
| **B3. `messages::get_inbox` 读接口夹带重度硬件 I/O** | `messages.rs:158-169` & `Inbox.tsx:118-125` | 前端每 8 秒调用一次 `get_inbox`，且每次收到 `sms-received` 事件也立即调用 `get_inbox`。而 `messages::get_inbox` 内部竟然每次都执行完整的 `sms::sync_inbox(c)`（枚举设备 -> 遍历 SIM 卡全部槽位 -> 逐条删除 SIM 卡短信）。当实时事件触发时，Modem 固件正在写入 SIM 卡槽位，前端立刻触发 `GetMessagesAsync` + `DeleteMessageAsync` 与 Modem 固件产生激烈的 AT/MBIM 总线冲突。 | 收信瞬间卡顿、SIM 卡读写返回 `0x80070015 (设备未就绪)` 或漏收 |
| **B4. 每次操作重复枚举 WinRT 设备，未复用句柄** | `sms/mod.rs:95` & `winrt.rs:165` | `resolve_channel("winrt")` 每次调用都 `WinRtChannel::new()` 创建全新的空实例，导致每次 `fetch_sim_info`、`send`、`sync_inbox`、`channel_status` 都要重新调用 `find_sms_device2()` 和 `find_sms_device_v1()`。 | 频繁跨进程查询 COM 设备管理器，增加延迟与失败率 |
| **B5. 送达回执（`SmsStatusMessage`）永不清理 SIM 卡槽位** | `winrt.rs:208-220` | `get_inbox` 遇到 `SmsStatusMessage` 时，推入 `PENDING_DELIVERY` 后直接 `continue`，**没有记录其 `item.Id()` 并调用 `DeleteMessageAsync`**！同样，空号码/空内容的异常短信在 `winrt.rs:236` 被过滤掉，也没有返回给上层删除。久而久之，SIM 卡的 20~50 个槽位被送达回执和异常 PDU 填满。 | 开启送达回执或运行一段时间后，SIM 卡槽位被回执塞满，彻底收不到新验证码 |
| **B6. 便携模式下群发线程写错数据库文件** | `broadcast.rs:341-345` | `db::init` 支持绿色便携模式（优先使用 `exe目录/data/smsclient.db`），但 `start_broadcast` 硬编码了 `app.path().app_data_dir().join("smsclient.db")`，导致便携模式下群发线程打开了 `%APPDATA%` 下的空库，任务状态永远无法同步！ | 绿色版群发功能失效、进度卡死 |

## 3. 架构级重构方案与最佳实践

### 3.1 彻底解耦 UI 线程、SQLite 锁与 WinRT 硬件 I/O
1. **将所有涉及硬件或耗时操作的 Tauri Command 改为 `async fn` + `tauri::async_runtime::spawn_blocking`**：确保 WebView UI 线程零阻塞。
2. **引入带超时的专用 MTA 工作线程执行 WinRT 调用（`run_winrt_with_timeout`）**：
   - Windows 蜂窝 API（`Windows.Devices.Sms`）在 **MTA（多线程套间）** 下表现最稳定，不会因等待 STA 消息泵而死锁。
   - 为硬件探测与 SIM 卡读写设置硬超时（如探测 3 秒超时、收发 10 秒超时），即使底层 `WwanSvc` 驱动假死，上层也能在 3 秒内优雅降级到 `MockChannel`，绝不挂起应用。
3. **缓存通道可用性与设备句柄（State Caching）**：
   - 维护全局 `ACTIVE_SMS_DEVICE_V1` 与 `ACTIVE_SMS_DEVICE_V2` 句柄缓存，并在超时或设备脱机时自动调用 `invalidate_device_cache()` 重置，避免前端打开页面并发请求 4 个接口时触发 4 次重复的硬件枚举。
4. **缩短 `DbState` 锁临界区（Lock Splitting）**：
   - **严禁在持有 `db.0.lock()` 期间调用任何 WinRT API**！
   - 正确流程：`短锁读配置` -> `释放锁，执行 WinRT 硬件探测/收发/删卡` -> `短锁批量写入 SQLite`。

### 3.2 统一实时事件与轮询管线（Single Ingestion Pipeline）
1. **`messages::get_inbox` 纯粹化**：`get_inbox` 只做**纯 SQLite 查询**（毫秒级返回），彻底移除里面的 `sms::sync_inbox(c)`。
2. **实时事件收到即入库**：`subscribe_inbox_events` 的回调收到短信后，立即通过 `DbState` 短锁去重入库，再向前端 emit `sms-received` 事件，前端调用纯查询的 `get_inbox` 即可瞬间渲染新验证码！
3. **修复 `ReceivedSms` 分片字段与去重窗口**：
   - 在 `WinRtChannel::get_inbox` 中完整提取 `PartNumber`、`PartCount`、`PartReferenceId`，与事件流保持一致。
   - 将 `inbox_exists` 去重逻辑升级为 `inbox_exists_recent`：**仅对最近 2 分钟内（`timestamp >= strftime('%Y-%m-%dT%H:%M:%SZ', 'now', '-2 minutes')`）同号码、同内容、同分片序号（`part_index`）的短信去重**。这样既能拦截“实时事件 + 轮询”对同一条物理短信的双重入库，又不会误杀用户 2 分钟后再次获取的相同验证码或指令。
4. **彻底清理 SIM 卡槽位**：无论是正常文本短信、PDU 二进制短信、还是 `SmsStatusMessage` 送达回执、甚至是解码失败的损坏短信，只要从 `MessageStore` 读出处理完毕，一律收集其 `device_id` 并执行 `DeleteMessageAsync`，保证 SIM 卡永不爆满。

```rust
                            if msgs.iter().any(|m| m.status != "read") {
                                let _ = bg_app.emit("sms-received", ());
                            }
                        }
                    }
                })
                .expect("failed to spawn sms-winrt-worker thread");

            Ok(())
        })
        .plugin(tauri_plugin_notification::init())
        .invoke_handler(tauri::generate_handler![
```

### 4.2 `src-tauri/src/sms/winrt.rs`（MTA 超时隔离 + 完整分片提取 + 全量清理 SIM 槽位 + 实时入库）

```rust
//! SMSClient — WinRT SMS 通道 (带超时隔离、MTA 安全执行、全槽位清理与实时入库)

use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{mpsc, Mutex, OnceLock};
use std::time::Duration;

use tauri::{Emitter, Manager};
use tauri_plugin_notification::NotificationExt;
use windows::core::Interface;
use windows::Devices::Enumeration::DeviceInformation;
use windows::Devices::Sms::{
    ISmsMessageBase, SmsBinaryMessage, SmsDevice, SmsDevice2, SmsDeviceStatus, SmsMessageFilter,
    SmsMessageReceivedEventArgs, SmsMessageReceivedEventHandler, SmsStatusMessage, SmsTextMessage,
    SmsTextMessage2,
};
use windows::Networking::Connectivity::{ConnectionProfile, NetworkInformation};
use windows::Win32::System::WinRT::{RoInitialize, RO_INIT_MULTITHREADED};

use super::channel::{MessageId, ReceivedSms, SmsChannel};
use crate::models::{ChannelStatus, NewMessage, SimInfo};

struct SmsDeviceHolder(SmsDevice);
unsafe impl Send for SmsDeviceHolder {}
unsafe impl Sync for SmsDeviceHolder {}

struct SmsDevice2Holder(SmsDevice2);
unsafe impl Send for SmsDevice2Holder {}
unsafe impl Sync for SmsDevice2Holder {}

static ACTIVE_SMS_DEVICE_V1: OnceLock<Mutex<Option<SmsDeviceHolder>>> = OnceLock::new();
static ACTIVE_SMS_DEVICE_V2: OnceLock<Mutex<Option<SmsDevice2Holder>>> = OnceLock::new();
static EVENT_SUBSCRIBED: AtomicBool = AtomicBool::new(false);

/// 事件驱动收到的短信缓冲区（兼容单元测试或兜底消费）
static PENDING_SMS: OnceLock<Mutex<Vec<NewMessage>>> = OnceLock::new();
/// 送达回执缓冲区
static PENDING_DELIVERY: OnceLock<Mutex<Vec<(String, String)>>> = OnceLock::new();

/// 在独立 MTA 线程中执行 WinRT 闭包，并施加硬超时保护，彻底杜绝 STA 死锁或驱动假死挂起
fn run_winrt_with_timeout<T, F>(timeout: Duration, task: F) -> Result<T, String>
where
    T: Send + 'static,
    F: FnOnce() -> Result<T, String> + Send + 'static,
{
    let (tx, rx) = mpsc::channel();
    std::thread::spawn(move || {
        unsafe {
            let _ = RoInitialize(RO_INIT_MULTITHREADED);
        }
        let res = task();
        let _ = tx.send(res);
    });

    match rx.recv_timeout(timeout) {
        Ok(res) => res,
        Err(mpsc::RecvTimeoutError::Timeout) => {
            invalidate_device_cache();
            Err(format!("WinRT 硬件响应超时 (>{}s)，设备可能休眠或不存在", timeout.as_secs()))
        }
        Err(mpsc::RecvTimeoutError::Disconnected) => {
            invalidate_device_cache();
            Err("WinRT 工作线程意外终止".into())
        }
    }
}

pub fn invalidate_device_cache() {
    if let Some(cell) = ACTIVE_SMS_DEVICE_V1.get() {
        if let Ok(mut g) = cell.lock() {
            *g = None;
        }
    }
    if let Some(cell) = ACTIVE_SMS_DEVICE_V2.get() {
        if let Ok(mut g) = cell.lock() {
            *g = None;
        }
    }
    EVENT_SUBSCRIBED.store(false, Ordering::SeqCst);
}

pub fn drain_delivery_reports() -> Vec<(String, String)> {
    let cell = PENDING_DELIVERY.get_or_init(|| Mutex::new(Vec::new()));
    match cell.lock() {
        Ok(mut buf) => buf.drain(..).collect(),
        Err(_) => Vec::new(),
    }
}

pub fn drain_pending_sms() -> Vec<NewMessage> {
    let cell = PENDING_SMS.get_or_init(|| Mutex::new(Vec::new()));
    match cell.lock() {
        Ok(mut buf) => buf.drain(..).collect(),
        Err(_) => Vec::new(),
    }
}

fn win_err(e: windows::core::Error) -> String {
    format!("WinRT 错误: {} (0x{:08X})", e.message(), e.code().0)
}

fn format_winrt_dt(dt: &windows::Foundation::DateTime) -> String {
    let ft = dt.UniversalTime as i64;
    let unix = (ft - 116_444_736_000_000_000) / 10_000_000;
    if unix <= 0 {
        return String::new();
    }
    let (h, m, sec) = (unix % 86400 / 3600, unix % 3600 / 60, unix % 60);
    let days = unix / 86400 + 719468;
    let era = days / 146097;
    let doe = (days - era * 146097) as u64;
    let yoe = (doe - doe / 1460 + doe / 36524 - doe / 146096) / 365;
    let y = yoe as i64 + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let d = doy - (153 * mp + 2) / 5 + 1;
    let mo = if mp < 10 { mp + 3 } else { mp - 9 };
    let yr = if mo <= 2 { y + 1 } else { y };
    format!("{:04}-{:02}-{:02}T{:02}:{:02}:{:02}Z", yr, mo, d, h, m, sec)
}

    let profiles = NetworkInformation::GetConnectionProfiles().ok()?;

    for i in 0..size {
        let p = profiles.GetAt(i).ok()?;

/// 内部探测 SmsDevice2（带全局缓存）
fn find_sms_device2_inner() -> Result<SmsDevice2, String> {
    let cell = ACTIVE_SMS_DEVICE_V2.get_or_init(|| Mutex::new(None));
    if let Ok(guard) = cell.lock() {
        if let Some(holder) = guard.as_ref() {
            if matches!(holder.0.DeviceStatus(), Ok(SmsDeviceStatus::Ready)) {
                return Ok(holder.0.clone());
            }
        }
    }

    let resolved = (|| -> Option<SmsDevice2> {
        if let Ok(dev) = SmsDevice2::GetDefault() {
            return Some(dev);
        }
        let selector = SmsDevice2::GetDeviceSelector().ok()?;
        let op = DeviceInformation::FindAllAsyncAqsFilter(&selector).ok()?;
        let devices = op.get().ok()?;
        let count = devices.Size().ok()?;
        for i in 0..count {
            if let Ok(info) = devices.GetAt(i) {
                if let Ok(id) = info.Id() {
                    if let Ok(dev) = SmsDevice2::FromId(&id) {
                        return Some(dev);
                    }
                }
            }
        }
        None
    })();

    match resolved {
        Some(dev) => {
            if let Ok(mut guard) = cell.lock() {
                *guard = Some(SmsDevice2Holder(dev.clone()));
            }
            Ok(dev)
        }
        None => Err("未检测到 4G/LTE 蜂窝设备 (SmsDevice2)".into()),
    }
}

/// 内部探测 SmsDevice v1（带全局缓存）
fn find_sms_device_v1_inner() -> Result<SmsDevice, String> {
    let cell = ACTIVE_SMS_DEVICE_V1.get_or_init(|| Mutex::new(None));
    if let Ok(guard) = cell.lock() {
        if let Some(holder) = guard.as_ref() {
            if holder.0.DeviceStatus().is_ok() {
                return Ok(holder.0.clone());
            }
        }
    }

    let resolved = (|| -> Option<SmsDevice> {
        if let Ok(op) = SmsDevice::GetDefaultAsync() {
            if let Ok(dev) = op.get() {
                return Some(dev);
            }
        }
        let selector = SmsDevice::GetDeviceSelector().ok()?;
        let op = DeviceInformation::FindAllAsyncAqsFilter(&selector).ok()?;
        let devices = op.get().ok()?;
        let count = devices.Size().ok()?;
        for i in 0..count {
            if let Ok(info) = devices.GetAt(i) {
                if let Ok(id) = info.Id() {
                    if let Ok(dev_op) = SmsDevice::FromIdAsync(&id) {
                        if let Ok(dev) = dev_op.get() {
                            return Some(dev);
                        }
                    }
                }
            }
        }
        None
    })();

    match resolved {
        Some(dev) => {
            if let Ok(mut guard) = cell.lock() {
                *guard = Some(SmsDeviceHolder(dev.clone()));
            }
            Ok(dev)
        }
        None => Err("未检测到 SMS 消息存储设备 (SmsDevice v1)".into()),
    }
}

        let msg_owned = message.to_string();
        run_winrt_with_timeout(Duration::from_secs(12), move || {
            let dev = find_sms_device2_inner()?;
            if !WinRtChannel::is_ready(&dev) {
                let st = dev.DeviceStatus().map_err(win_err)?;
                invalidate_device_cache();

                .map_err(win_err)?;
            text_msg
                .SetBody(&windows::core::HSTRING::from(&msg_owned))
                .map_err(win_err)?;
            let base: ISmsMessageBase = text_msg.cast().map_err(win_err)?;
            let res = dev
                .SendMessageAndGetResultAsync(&base)
                .map_err(win_err)?
                .get()
                .map_err(win_err)?;
            if !res.IsSuccessful().unwrap_or(false) {
                let err_code = res.CellularClass().ok();
                return Err(format!("运营商拒绝或发送失败 (CellularClass={err_code:?})"));
            }
            Ok(0)
        })

    async fn get_inbox(&self) -> Result<Vec<ReceivedSms>, String> {
        run_winrt_with_timeout(Duration::from_secs(8), move || {
            let dev1 = find_sms_device_v1_inner()?;
            let store = dev1.MessageStore().map_err(win_err)?;
            let messages = store
                .GetMessagesAsync(SmsMessageFilter::All)
                .map_err(win_err)?
                .get()
                .map_err(win_err)?;

            let mut result = Vec::new();
            let size = messages.Size().map_err(win_err)?;
            for i in 0..size {
                let item = match messages.GetAt(i) {
                    Ok(it) => it,
                    Err(_) => continue,
                };
                let device_id = item.Id().unwrap_or(0);

                // 1. 送达回执检测 — SmsStatusMessage（处理后立即从 SIM 卡清理，防止回执塞满卡槽！）
                if let Ok(status_msg) = item.cast::<SmsStatusMessage>() {
                    if let Ok(to) = status_msg.To() {
                        let to_str = to.to_string();
                        if let Ok(st) = status_msg.Status() {
                            let s = if st == 0 {
                                "delivered".into()
                            } else {
                                "failed".into()
                            };
                            let cell = PENDING_DELIVERY.get_or_init(|| Mutex::new(Vec::new()));
                            if let Ok(mut buf) = cell.lock() {
                                buf.push((to_str, s));
                            }
                        }
                    }
                    if device_id > 0 {
                        if let Ok(act) = store.DeleteMessageAsync(device_id) {
                            let _ = act.get();
                        }
                    }
                    continue;
                }

                // 2. 兼容普通文本短信与二进制 PDU 短信
                let text_msg_opt = if let Ok(text_msg) = item.cast::<SmsTextMessage>() {
                    Some(text_msg)
                } else if let Ok(bin) = item.cast::<SmsBinaryMessage>() {
                    SmsTextMessage::FromBinaryMessage(&bin).ok()
                } else {
                    None
                };

                if let Some(text_msg) = text_msg_opt {
                    let from = text_msg.From().map(|s| s.to_string()).unwrap_or_default();
                    let body = text_msg.Body().map(|s| s.to_string()).unwrap_or_default();
                    let timestamp = text_msg
                        .Timestamp()
                        .map(|dt| format_winrt_dt(&dt))
                        .unwrap_or_default();

                    if !from.is_empty() && !body.is_empty() {
                        result.push(ReceivedSms {
                            from,
                            body,
                            timestamp,
                            device_id,
                        });
                    } else if device_id > 0 {
                        // 空消息直接清理槽位
                        if let Ok(act) = store.DeleteMessageAsync(device_id) {
                            let _ = act.get();
                        }
                    }
                } else if device_id > 0 {
                    // 无法识别/损坏的 PDU 也清理槽位，防止永久卡死 SIM 容量
                    if let Ok(act) = store.DeleteMessageAsync(device_id) {
                        let _ = act.get();
                    }
                }
            }
            Ok(result)
        })
    }

    async fn delete_message(&self, id: MessageId) -> Result<(), String> {

            return Ok(());
        }
        run_winrt_with_timeout(Duration::from_secs(5), move || {

            let action = store.DeleteMessageAsync(id).map_err(win_err)?;
            action.get().map_err(win_err)?;

        })
    }

    async fn get_signal_strength(&self) -> Result<i32, String> {

                .GetSignalBars()

                .unwrap_or(0);

                4 => -60,
                3 => -75,
                2 => -85,
                1 => -95,
                0 => -110,
                _ => -100,
            })
        })

    async fn get_sim_info(&self) -> Result<SimInfo, String> {
        run_winrt_with_timeout(Duration::from_secs(3), move || {
            let dev = find_sms_device2_inner()?;
            let wwan = find_wwan_profile();

            let carrier = wwan
                .as_ref()
                .and_then(|p| p.GetNetworkNames().ok())
                .and_then(|n| n.GetAt(0).ok().map(|s| s.to_string()))
                .filter(|s| !s.is_empty())
                .unwrap_or_else(|| "未知运营商".to_string());

            let signal_dbm = wwan
                .as_ref()
                .and_then(|p| p.GetSignalBars().ok())
                .and_then(|b| b.Value().ok())
                .map(|bars| match bars {
                    4 => -60,
                    3 => -75,
                    2 => -85,
                    1 => -95,
                    0 => -110,
                    _ => -100,
                })
                .unwrap_or(-100);
            let signal_strength =
                ((signal_dbm + 100) as f32 / 50.0 * 100.0).clamp(0.0, 100.0) as i32;

            let phone_number = dev
                .AccountPhoneNumber()
                .ok()
                .map(|s| s.to_string())
                .filter(|s| !s.is_empty() && s != "+00000000000");

            Ok(SimInfo {
                carrier,
                signal_strength,
                signal_dbm,
                network_type: network_type.to_string(),
                iccid: "N/A (WinRT)".into(),
                imsi: "N/A (WinRT)".into(),
                phone_number,
            })
        })
    }

    async fn status(&self) -> ChannelStatus {
        match run_winrt_with_timeout(Duration::from_secs(3), move || {

            let ready = WinRtChannel::is_ready(&dev);
            let err_msg = if ready {

                Some(format!("DeviceStatus={:?}", dev.DeviceStatus()))

                com_port: None,
                error,
            },
            Err(e) => ChannelStatus {
                channel_type: "winrt".into(),
                available: false,
                com_port: None,
                error: Some(e),
            },
        }
    }

pub fn subscribe_inbox_events(app_handle: tauri::AppHandle) -> Result<(), String> {
    run_winrt_with_timeout(Duration::from_secs(4), move || {
        let dev = find_sms_device_v1_inner()?;
        let app_for_event = app_handle.clone();
        let handler = SmsMessageReceivedEventHandler::new(
            move |_sender: windows::core::Ref<'_, SmsDevice>,
                  args: windows::core::Ref<'_, SmsMessageReceivedEventArgs>| {
                let Some(args_ref) = args.as_ref() else {
                    return Ok(());
                };
                let text_msg_opt = if let Ok(text_msg) = args_ref.TextMessage() {
                    Some(text_msg)
                } else if let Ok(bin) = args_ref.BinaryMessage() {
                    SmsTextMessage::FromBinaryMessage(&bin).ok()
                } else {
                    None
                };

                if let Some(text_msg) = text_msg_opt {
                    let raw_from = text_msg.From().map(|s| s.to_string()).unwrap_or_default();
                    let phone = crate::contacts::normalize_phone(&raw_from);
                    let body = text_msg
                        .Body()
                        .map(|s| s.to_string())
                        .unwrap_or_default()
                        .trim()
                        .to_string();
                    if phone.is_empty() || body.is_empty() {
                        return Ok(());
                    }

                    let timestamp = text_msg
                        .Timestamp()
                        .ok()
                        .map(|dt| format_winrt_dt(&dt))
                        .filter(|s| !s.is_empty());

                    let part_num = text_msg.PartNumber().unwrap_or(1) as i64;
                    let part_count = text_msg.PartCount().unwrap_or(1) as i64;
                    let ref_id = text_msg.PartReferenceId().unwrap_or(0);
                    let is_long = part_count > 1;
                    let group_id = if is_long {
                        Some(format!("{phone}_{ref_id}"))
                    } else {
                        None
                    };

                    let msg = NewMessage::incoming_with_meta(
                        phone.clone(),
                        body.clone(),
                        timestamp,
                        is_long,
                        part_num,
                        part_count,
                        group_id,
                    );

                    // 1. 立即通过短锁去重入库（确保前端任何页面收到事件后查询 DB 都有数据！）
                    let mut inserted = false;
                    let mut notify_enabled = true;
                    let db = app_for_event.state::<crate::db::DbState>();
                    let _ = db.with(|conn| {
                        if !crate::sms::inbox_exists_recent(conn, &phone, &body, part_num).unwrap_or(false) {
                            if crate::messages::insert(conn, &msg).is_ok() {
                                inserted = true;
                            }
                        }
                        notify_enabled = crate::settings::get(conn, "notify_enabled")
                            .ok()
                            .flatten()
                            .map(|s| s != "false")
                            .unwrap_or(true);
                        Ok(())
                    });

                    if inserted {
                        // 2. 通知前端刷新
                        let _ = app_for_event.emit(
                            "sms-received",
                            serde_json::json!({
                                "phone": phone,
                                "content": body,
                            }),
                        );
                        // 3. 弹出系统通知
                        if notify_enabled {
                            let _ = app_for_event
                                .notification()
                                .builder()
                                .title(format!("新短信 {phone}"))
                                .body(&body)
                                .show();
                        }
                    }
                }
                Ok(())
            },
        );
        dev.SmsMessageReceived(&handler).map_err(win_err)?;
        EVENT_SUBSCRIBED.store(true, Ordering::SeqCst);
        eprintln!("[smsclient] WinRT 短信事件监听器已成功挂载");
        Ok(())
    })
}
```

```rust
impl Wake for ThreadWaker {

pub fn block_on<F: Future>(f: F) -> F::Output {
    let mut f = Box::pin(f);
    let waker = Waker::from(Arc::new(ThreadWaker(thread::current())));
    let mut cx = Context::from_waker(&waker);
    loop {
        match f.as_mut().poll(&mut cx) {
            Poll::Ready(val) => return val,
            Poll::Pending => thread::park(),
        }
    }
}

/// 3. 短锁去重入库 + 消费送达回执
/// 4. 无锁清理 SIM 卡槽位
pub fn sync_inbox_non_blocking(db: &DbState) -> Result<Vec<SmsMessage>, String> {
    let pref = db.with(|c| Ok(preferred_channel(c))).unwrap_or_else(|_| "winrt".into());
    let ch = channel_or_fallback(&pref);

    // 无锁拉取设备短信
    let received = block_on(ch.get_inbox())?;
    let pending_events = crate::sms::winrt::drain_pending_sms();
    let delivery_reports = crate::sms::winrt::drain_delivery_reports();

    // 短锁批量入库
    let list = db
        .with(|conn| {
            for msg in pending_events {
                if !inbox_exists_recent(conn, &msg.phone, &msg.content, msg.part_index)? {
                    let _ = crate::messages::insert(conn, &msg);
                }
            }
            for r in &received {
                let phone = crate::contacts::normalize_phone(&r.from);
                let body = r.body.trim();
                if phone.is_empty() || body.is_empty() {
                    continue;
                }
                if !inbox_exists_recent(conn, &phone, body, 1)? {
                    let nm = crate::models::NewMessage::incoming_with_meta(
                        phone,
                        body.to_string(),
                        if r.timestamp.is_empty() {
                            None
                        } else {
                            Some(r.timestamp.clone())
                        },
                        false,
                        1,
                        1,
                        None,
                    );
                    let _ = crate::messages::insert(conn, &nm)?;
                }
            }
            for (raw_phone, status) in delivery_reports {
                let phone = crate::contacts::normalize_phone(&raw_phone);
                if let Ok(id) = conn.query_row(
                    "SELECT id FROM messages WHERE direction='out' AND phone=?1 AND status='sent' \
                     ORDER BY id DESC LIMIT 1",
                    rusqlite::params![phone],
                    |row| row.get::<_, i64>(0),
                ) {
                    let _ = crate::messages::set_status(conn, id, &status, None);
                }
            }
            crate::messages::list(conn, Some("in"), 200)
        })
        .map_err(db_err)?;

    // 释放 DB 锁后，逐条清理 SIM 卡槽位
    for r in received {
        if r.device_id > 0 {
            if let Err(e) = block_on(ch.delete_message(r.device_id)) {
                eprintln!("[smsclient] 清理 SIM 卡短信 (id={}) 提示: {e}", r.device_id);
            }
        }
    }

    Ok(list)
}

/// 精准时间窗口去重：仅对最近 120 秒内相同号码、相同正文、相同分片的短信判重，
/// 既能消除“事件监听 + 轮询”双重入库，又不会误杀后续重发的相同验证码！
pub fn inbox_exists_recent(
    conn: &Connection,
    phone: &str,
    content: &str,
    part_index: i64,
) -> rusqlite::Result<bool> {
    let n: i64 = conn.query_row(
        "SELECT COUNT(*) FROM messages \
         WHERE direction = 'in' AND phone = ?1 AND content = ?2 AND part_index = ?3 \
         AND timestamp >= strftime('%Y-%m-%dT%H:%M:%SZ', 'now', '-2 minutes')",
        params![phone, content, part_index],
        |row| row.get(0),
    )?;
    Ok(n > 0)
}

pub fn inbox_exists(conn: &Connection, phone: &str, content: &str) -> rusqlite::Result<bool> {
    let n: i64 = conn.query_row(
        "SELECT COUNT(*) FROM messages WHERE direction = 'in' AND phone = ?1 AND content = ?2",
        params![phone, content],
        |row| row.get(0),
    )?;
    Ok(n > 0)
}

pub fn sync_inbox(conn: &Connection) -> Result<Vec<SmsMessage>, String> {
    let ch = active_channel(conn);
    sync_inbox_with(conn, &ch)
}

pub fn sync_inbox_with(conn: &Connection, ch: &Channel) -> Result<Vec<SmsMessage>, String> {
    let received = block_on(ch.get_inbox())?;
    for r in received {
        let phone = crate::contacts::normalize_phone(&r.from);
        if phone.is_empty() || r.body.trim().is_empty() {
            if r.device_id > 0 {
                let _ = block_on(ch.delete_message(r.device_id));
            }
            continue;
        }
        let exists = inbox_exists_recent(conn, &phone, r.body.trim(), 1).map_err(db_err)?;
        if !exists {
            let nm = crate::models::NewMessage::incoming_with_meta(
                phone,
                r.body.trim().to_string(),
                if r.timestamp.is_empty() {
                    None
                } else {
                    Some(r.timestamp.clone())
                },
                false,
                1,
                1,
                None,
            );
            let _ = crate::messages::insert(conn, &nm).map_err(db_err)?;
        }
        if r.device_id > 0 {
            let _ = block_on(ch.delete_message(r.device_id));
        }
    }
    crate::messages::list(conn, Some("in"), 200).map_err(db_err)
}

fn db_err(e: rusqlite::Error) -> String {
    match e {
        rusqlite::Error::InvalidParameterName(msg) => msg,
        other => format!("数据库错误: {other}"),
    }
}
```

```rust
// src-tauri/src/db.rs 新增辅助函数
pub fn resolve_db_path(app: &tauri::AppHandle) -> Result<std::path::PathBuf> {
    let portable_dir = std::env::current_exe()
        .ok()
        .and_then(|p| p.parent().map(|d| d.join("data")))
        .filter(|d| d.exists() && d.is_dir());

    let dir = if let Some(p) = portable_dir {
        p
    } else {
        let app_dir = app
            .path()
            .app_data_dir()
            .map_err(|e| rusqlite::Error::InvalidParameterName(format!("app_data_dir: {e}")))?;
        std::fs::create_dir_all(&app_dir)
            .map_err(|e| rusqlite::Error::InvalidParameterName(format!("create_dir_all: {e}")))?;
        app_dir
    };
    Ok(dir.join("smsclient.db"))
}
```
