1. 项目概述

1.1 项目定位

SMSClient 是一款运行在 Windows 桌面端的短信收发客户端，通过蜂窝网络（4G/LTE）收发短信，支持中文、长短信拼接、群发、送达回执等功能，可单文件 exe 分发给其他朋友使用。

1.2 核心目标

优先级目标验收标准
P0收发真实短信双击 exe → 发一条短信到手机 → 手机回复 → exe 收到并显示
P0不影响 4G 上网收发短信全程，已有 4G 数据连接不中断
P1中文支持支持 UCS2 中文短信、>70 字自动长短信拆分
P1本地持久化短信存 SQLite，支持导出 CSV/文本
P1群发能力多号码/通讯录导入，发送失败自动重试
P2送达/读取报告AT 层回执自动解析入库
P2桌面通知新短信到达时系统通知 + 声音提醒
P2联系人管理简易版，支持手动添加 + CSV 导入

1.3 不做的事（v1.0 排除）

  • 自动回复 / 规则引擎（留给 v2.0）
  • 语音通话、RCS / iMessage
  • 端到端加密
  • 多 SIM 卡同时在线

2.4 USB 组合与 AT 口分析

当前 USB 组合 (PID_0310, 仅 2 个接口)

MI_00 → Quectel GNSS Sensor Device   (Sensor 类)
MI_01 → Quectel EM05-CN MBIM 网卡    (Net 类, 上网用)
缺少 MI_03/04/05 (无 AT 串口)

目标 USB 组合 (PID_0312, 5 个接口)

MI_00 → Quectel GNSS Sensor   (Sensor, 保留)
MI_01 → Quectel EM05-CN MBIM  (Net, 保留, 上网不中断)
MI_03 → Quectel DM DIAG 串口   (qcser, COM 口)
MI_04 → Quectel NMEA GPS 串口  (qcser, COM 口)
MI_05 → Quectel AT2 命令串口   (qcser, COM 口) ★ 核心
切换代价：PID_0310→0312 切换需 AT 指令或 USB 控制传输，切换瞬间 4G 会断开重连约 10-30 秒。qusbccgp.inf 同时支持两个 PID，驱动就绪。

4.2 SMS 通道抽象层

// 通道 trait —— 无论 WinRT 还是 AT，上层逻辑统一
pub trait SmsChannel: Send + Sync {
    async fn send_sms(&self, to: &str, msg: &str) -> Result<MessageId>;
    async fn get_inbox(&self) -> Result<Vec<SmsMessage>>;
    async fn delete_message(&self, id: MessageId) -> Result<()>;
    async fn get_signal_strength(&self) -> Result<SignalInfo>;
    async fn get_sim_info(&self) -> Result<SimInfo>;
}
  • 通道 A (WinRT SMS): 通过 windows crate 调用 Windows.Devices.Sms.SmsDevice2，无需 COM 口，不影响上网
  • 通道 B (AT Serial): 通过 tokio-serial 调用 AT+CMGS/CMGL/CMGR，需 MI_05 AT 口就绪

5. 数据模型

5.1 SQLite 表结构

-- 联系人表
CREATE TABLE contacts (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    phone       TEXT NOT NULL UNIQUE,
    note        TEXT,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 短信表
CREATE TABLE messages (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    direction   TEXT CHECK(direction IN ('in', 'out')) NOT NULL,
    phone       TEXT NOT NULL,
    content     TEXT NOT NULL,
    encoding    TEXT DEFAULT 'UCS2',
    is_long     BOOLEAN DEFAULT 0,
    part_index  INTEGER DEFAULT 1,
    part_total  INTEGER DEFAULT 1,
    group_id    TEXT,
    status      TEXT DEFAULT 'pending',
    error       TEXT,
    timestamp   DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 群发任务表
CREATE TABLE broadcast_tasks (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    content     TEXT NOT NULL,
    total       INTEGER NOT NULL,
    sent        INTEGER DEFAULT 0,
    failed      INTEGER DEFAULT 0,
    status      TEXT DEFAULT 'pending',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 设置表
CREATE TABLE settings (
    key   TEXT PRIMARY KEY,
    value TEXT NOT NULL
);

5.2 核心数据类型 (TypeScript)

interface SmsMessage {
  id: number;
  direction: 'in' | 'out';
  phone: string;
  content: string;
  encoding: string;
  isLong: boolean;
  status: 'pending' | 'sent' | 'delivered' | 'read' | 'failed';
  timestamp: string;
}

interface SimInfo {
  carrier: string;
  iccid: string;
  signalStrength: number;   // 0-100
  signalDbm: number;        // -120 to -30
  networkType: string;      // 'LTE' | 'HSPA+' | '3G' | '2G'
}

6. 功能需求详述

F1. 收件箱 (P0)

  • 会话视图：按联系人/号码聚合短信
  • 实时监听新短信（WinRT 事件回调 → Tauri emit → 前端 listen）
  • 短信详情：内容、时间戳、送达状态、编码方式
  • 搜索：按号码或内容关键词
  • 分页加载（虚拟滚动，应对大量短信）

F2. 写短信 / 发送 (P0)

  • 收件人输入：手动输入号码 + 联系人选择器
  • 内容输入：支持中文
  • 长短信自动拆分：>70 中文字符自动 UCS2 拆分，显示"已拆为 N 条"
  • 发送确认：二次确认弹窗
  • 发送状态：实时更新 (pending → sent → delivered)
  • 重发：失败后一键重发

F3. 群发 (P1)

  • 收件人来源：手动多选 + CSV 导入 + 通讯录选择
  • 进度显示：已发/总数/失败数
  • 失败重试：自动重试 2 次，间隔 5 秒
  • 防骚扰限速：可配置每分钟最大发送条数（默认 10 条/分钟）

F4~F8. 其他功能

模块优先级关键点
F4. 送达/读取报告P2AT 层 SRI 报告 + WinRT DeliveryStatus 枚举
F5. 本地持久化P1SQLite + CSV 导出 + 文本备份
F6. 桌面通知P2Windows toast 通知 + 声音提醒
F7. 联系人管理P2增删改 + CSV 导入
F8. 设置页面P1通道切换、通知、限速、导出、主题
