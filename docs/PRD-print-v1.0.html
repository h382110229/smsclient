1. 项目概述

1.1 项目定位

SMSClient 是运行在 Windows 桌面端的短信收发客户端，通过蜂窝网络（4G/LTE）收发短信，支持中文、长短信拼接、群发、送达回执，可单文件 exe 分发给朋友使用。

1.2 核心目标

优先级目标验收标准
P0收发真实短信双击 exe → 发短信到手机 → 手机回复 → exe 收到并显示
P0不影响 4G 上网收发全程 ping 223.5.5.5 不中断
P1中文支持UCS2 中文短信，>70 字自动拆分拼接
P1本地持久化SQLite 存储，导出 CSV/文本
P1群发能力多号码/CSV 导入，失败自动重试
P2回执/通知/联系人DeliveryStatus 入库 · Toast 通知 · 简易通讯录

1.3 不做的事（v1.0 排除）

❌ 自动回复/规则引擎 · ❌ 语音通话 · ❌ RCS/iMessage · ❌ 端到端加密 · ❌ 多 SIM 同时在线

    async fn delete_message(&self, id: MessageId) -> Result<()>;
    async fn get_signal_strength(&self) -> Result<SignalInfo>;
    async fn get_sim_info(&self) -> Result<SimInfo>;
