1. 项目概述

1.1 项目定位

SMSClient 是一款运行在 Windows 桌面端的 短信收发客户端，通过蜂窝网络(4G/LTE)收发短信，支持中文、长短信拼接、群发、送达回执等功能，可单文件 exe 分发给其他朋友使用。

1.2 核心目标

优先级目标验收标准
P0收发真实短信双击 exe 发送短信到手机，手机回复，exe 收到并显示
P0不影响 4G 上网收发短信全程，已有的 4G 数据连接(ping 223.5.5.5)不中断
P1中文支持支持 UCS2 中文短信、70 字自动长短信拆分拼接
P1本地持久化短信存 SQLite，支持导出 CSV/文本
P1群发能力多号码/通讯录导入，发送失败自动重试
P2送达/读取报告AT 层回执自动解析入库
P2桌面通知新短信到达时系统通知+声音提醒
P2联系人管理简易版，支持手动添加+CSV 导入

2.3 USB 组合与 AT 口分析

当前 USB 组合 (PID_0310, 2 个接口):

  • MI_00 → Quectel GNSS Sensor Device (Sensor 口, 保留)
  • MI_01 → Quectel EM05-CN MBIM 网卡 (Net 口, 保留, 上网不中断)

目标 USB 组合 (PID_0312, 5 个接口, qcser.inf 已支持):

  • MI_00 → Quectel GNSS Sensor Device (Sensor 口, 保留)
  • MI_01 → Quectel EM05-CN MBIM 网卡 (Net 口, 保留, 上网不中断)
  • MI_03 → Quectel DM DIAG 串口 (qcser 驱动, COM 口)
  • MI_04 → Quectel NMEA GPS 串口 (qcser 驱动, COM 口)
  • MI_05 → Quectel AT2 命令串口 (qcser 驱动, COM 口, 通道 B)
