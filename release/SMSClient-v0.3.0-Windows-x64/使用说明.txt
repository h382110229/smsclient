【使用要求】
1. 硬件要求：
   - 适用于内置 4G/LTE 蜂窝网卡及 SIM 卡槽的笔记本电脑或平板电脑（如 ThinkPad、Surface Pro LTE/5G、Dell Latitude、HP EliteBook 等）。
   - 插入有效 SIM 卡，并确保 Windows 系统右下角网络或「设置 -> 网络和 Internet -> 手机网络」已正常连接。

2. 系统设置（重要）：
   - 请确保 Windows 隐私设置中允许应用访问短信：
     进入系统「设置」 -> 「隐私和安全性」 -> 「消息 / 短信」 -> 开启“允许应用访问你的消息”。

3. 绿色便携模式：
   - 本程序为单文件绿色独立版本，解压即用，无需安装。
   - 若希望短信数据库与配置完全跟随程序移动（如存放于 U 盘），只需在 smsclient.exe 同级目录下新建一个名为「data」的文件夹，软件将自动把数据库存放于该目录下。

【v0.3.0 终极架构重构更新日志】
1. [秒开体验] 彻底解决 Windows COM STA 主线程死锁与同步 Command 卡死问题，启动耗时由 10~30 秒降至 0.1 秒秒开，彻底消除白屏“未响应”；
2. [MTA 隔离与超时熔断] 引入 RoInitialize(RO_INIT_MULTITHREADED) 常驻工作线程与分级超时熔断（发信 15s、探测未命中 6s、热态 2.5s），即便 WWAN 驱动假死也绝不挂起界面；
3. [Singleflight 并发互斥] 增加 PROBE_LOCK 并发探测互斥锁，彻底杜绝开机多 Command 并发引发的硬件总线冲突风暴；
4. [2分钟时间窗精准防误杀] 去重升级为基于 SQLite datetime(timestamp) >= datetime('now', '-2 minutes') 滑动窗口，消除双通道重复入库并彻底杜绝连续重发相同验证码时的静默误杀；
5. [长短信与全卡槽清理] 完整提取长短信分片信息并保持语序，全量清理包括 SmsStatusMessage 送达回执在内的所有卡槽，防止 SIM 存储满额断收；
6. [休眠自愈重连] 后台心跳增加时钟跳变检测（elapsed > 25s），自动识别 Modern Standby 盒盖睡眠唤醒并自愈重连；
7. [便携模式路径统一] 统一绿色便携模式下的 resolve_db_path，修复群发任务数据库路径不一致问题。
