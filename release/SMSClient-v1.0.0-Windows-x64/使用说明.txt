========================================================================
                      SMSClient v1.0.0 (绿色便携版)
              Windows 4G/LTE 蜂窝短信桌面客户端 (Official Release)
========================================================================

【快速启动】
1. 双击运行当前目录下的 `smsclient.exe` 即可直接使用，无需任何安装或管理员权限。
2. 数据存储在运行目录下的 `smsclient.db`，实现完全的绿色便携。

【v1.0.0 正式版核心特性】
1. 完整长短信自动拼接（Concatenated SMS）：
   - 支持跨运营商切片短信智能合并，200字以上长短信与验证码自动聚合为单个完整气泡，告别多行断句阅读困扰。
2. 会话列表精准时序：
   - 修复长短信接收后最新时间更新机制，新短信即刻置顶提醒。
3. 双模自愈实时驱动引擎：
   - WinRT 事件驱动即时推送（毫秒级通知与入库） + 8s 静默心跳双兜底，绝不漏收任何后续短信。
4. 终极架构解耦（Gemini 4 审阅拍板）：
   - 彻底解决开机并发与硬件冷态探测争用；
   - 消除 UI 白屏未响应与死锁问题；
   - 引入 Modern Standby 盒盖睡眠唤醒自愈与 SIM 卡槽位全自动清理。

【系统要求】
- Windows 10 (1809 及以上) 或 Windows 11 (22H2 / 23H2 / 24H2)
- 内置或外接 4G/5G 蜂窝数据网卡（如移远 Quectel EM05-CN、EM12、Fibocom 等支持 WinRT WWAN 的模块）
