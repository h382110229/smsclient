                      SMSClient v0.2.0 (绿色便携版)
              Windows 4G/LTE 蜂窝短信桌面客户端 (ASTeam)
========================================================================

【使用要求】
1. 硬件要求：
   - 适用于内置 4G/LTE 蜂窝网卡及 SIM 卡槽的笔记本电脑或平板电脑（如 ThinkPad、Surface Pro LTE/5G、Dell Latitude、HP EliteBook 等）。
   - 插入有效 SIM 卡，并确保 Windows 系统右下角网络或「设置 -> 网络和 Internet -> 手机网络」已正常连接。

2. 系统设置（重要）：
   - 请确保 Windows 隐私设置中允许应用访问短信：
     进入系统「设置」 -> 「隐私和安全性」 -> 「消息 / 短信」 -> 开启“允许应用访问你的消息”。

3. 绿色便携模式：
   - 本程序为单文件绿色独立版本，解压即用，无需安装。
   - 若希望短信数据库与配置完全跟随程序移动（如存放于 U 盘），只需在 smsclient.exe 同级目录下新建一个名为「data」的文件夹，软件将自动把数据库存放于该目录下。

【v0.2.0 版本更新日志】
1. [兼容性增强] 重构 WinRT 蜂窝设备智能枚举器，支持任意带有 SIM 模块的 Windows 笔记本与平板独立运行；
2. [时区修复] 全面修复接收短信时间戳偏差 8 小时的时区显示问题，统一规范为 ISO-8601 UTC 并自动匹配系统本地时间；
3. [长短信拼合] 支持运营商长短信（Concatenated SMS）分片序号解析，按语序升序排列并连续展示，不再颠倒错位；
4. [防卡死收信] 短信入库后立即自动清理 SIM 卡/设备端有限存储（彻底解决连续收几条后因卡存储容量满而无法继续收信的问题）；
5. [稳定性保障] WinRT 事件监听器常驻内存防释放，并引入后台 15 秒心跳静默同步机制，防止休眠唤醒或事件丢包导致收不到短信。
